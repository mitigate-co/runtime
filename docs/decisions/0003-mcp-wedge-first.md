# ADR-0003: MCP Wedge Before Broad Suite

Status: Accepted  
Date: 2026-09-27

## Context

The broad platform roadmap is valuable but too large to ship credibly as an initial product. The strongest near-term category wedge is MCP discovery/governance.

## Decision

Build Mitigate MCP scanner + gateway + registry/fleet sync first. Park Router, Trace, Behavior, Evals, Work, Sandbox and Models until MCP launch/retention evidence or explicit owner reprioritization.

## Consequences

- smaller executable surface,
- faster security hardening,
- clearer adoption story,
- roadmap docs remain but are non-executable.
